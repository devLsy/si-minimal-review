# si-core-v1

SI 실무에서 반복적으로 사용되는 핵심 기능들을  
필요할 때 빠르게 복기하고 재구성하기 위한 개인용 Spring Boot 프로젝트입니다.

학습용 예제나 데모 목적이 아니라,  
실제 업무 투입 전 구조를 다시 떠올리기 위한 최소 단위 정리를 목표로 합니다.

260409 리액트 학습을 하기 위해 잠정 보류됨

---

## 목적

- SI 프로젝트에서 자주 사용되는 기본 구조 복기
- 권한, 사용자/관리자, 게시판 등 반복되는 패턴 정리
- 완성도보다 **구조 이해와 재사용성**에 집중

---

## 범위

- 인증 / 인가 기본 구조
- 사용자 / 관리자 도메인 분리
- 게시판 등 SI에서 흔한 CRUD 패턴
- 공통 예외 처리 및 기본 설정

필요 최소한의 기능만 구현하며,  
과도한 추상화나 불필요한 기능은 포함하지 않습니다.

---

## 기술 스택

- Java 21+
- Spring Boot 3.5.x
- Spring Security
- Mybatis
- Gradle

---

## 참고

- 개인 복기 및 리마인드 용도
- 실무 감각 유지를 위한 내부 정리 프로젝트
- 포트폴리오 목적 아님
